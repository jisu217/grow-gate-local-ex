## 🎯 핵심 메시지 (3줄 요약)

1. **마이페이지 = 수출 준비 상태 대시보드.** 회사·제품·진단·할일을 한 화면에서 "현황 → 결과 → 액션 → 실행" 흐름으로 연결한다.
2. **기존 자산을 최대한 재활용.** DB(ERD)·API의 70%는 이미 존재 → 마이페이지 관점으로 재정리하고, 부족한 부분만 신규 제안.
3. **빠진 부분을 짚었다.** 리포트 보관함용 `reports` 테이블 / `GET /api/report/{run_id}` / 팀원 권한 API가 현재 명세에 없어 추가 제안.

---

## 🔍 작업 중 발견한 개선 포인트 (어필 포인트)

- **reports 테이블 부재**: 과제가 요구한 "리포트 보관함"을 위한 테이블이 ERD에 없어 신규 설계안 제시.
- **API 명세 불일치**: 제품 경로(`/api/products` vs `/api/mypage/knowledge`)와 수정 메서드(PUT vs PATCH)가 문서마다 달라 통일 필요. (현재 백엔드 코드 기준 = `/api/products`, `PUT`)
- **개인/기업 계정 분기**: 회사 정보·팀원 권한 카드는 기업 계정에서만 노출되도록 화면 상태 분기 설계.
