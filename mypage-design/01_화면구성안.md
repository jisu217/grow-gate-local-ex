## 1. 마이페이지의 역할 정의

마이페이지는 단순 회원정보 조회 화면이 아니라,
**로그인한 사용자가 "내 수출 준비 상태"를 한눈에 파악하고 다음 행동으로 바로 넘어가는 대시보드**다.

핵심 질문: *"내가 사용자라면 로그인하고 나서 뭘 제일 먼저 보고 싶을까?"*
- 내 회사/제품이 지금 어떤 상태인지 (현황)
- AI 진단을 마지막으로 언제, 어떤 결과로 받았는지 (결과)
- 오늘 당장 뭘 해야 하는지 (액션)
- 막힌 게 있으면 바로 진단을 다시 돌릴 수 있는지 (실행)

→ **"현황 → 결과 → 액션 → 실행"** 흐름이 한 화면에서 끝나는 것을 목표로 한다.

## 2. 카드 구성 (8개 + 메뉴)

| # | 카드명 | 보여줄 내용 | 왜 필요한가 | 데이터 출처(API) |
| :-- | :--- | :--- | :--- | :--- |
| 1 | **회사 정보 카드** | 기업명, 업종, 사업자번호, 담당자명 | 진단/제품의 기준이 되는 내 소속 정보 확인·수정 진입점 | `GET /api/companies/me` |
| 2 | **제품 지식 현황 카드** | 등록 제품 수, 신뢰도 등급 분포(high/medium/low), **만료 임박 인증서 개수**, 최근 수정일 | 내 제품 데이터가 진단에 쓸 만큼 충실한지 한눈에 점검 | `GET /api/products` |
| 3 | **최근 AI 진단 결과 카드** | 가장 최근 진단의 전체 점수, 요약, 상태(pending/done/failed), 요청일 | 마지막 진단 상태를 즉시 확인하고 결과 페이지로 이동 | `GET /api/diagnosis` (최신 1건) |
| 4 | **리포트 보관함 카드** | 완료된 진단 리포트 목록(제품명·국가·점수·생성일), 다운로드/조회 | 과거 진단 결과를 자료로 보관·재열람 | `GET /api/report/{run_id}` ※신규 필요 |
| 5 | **오늘 할 일 카드** | 최근 진단의 30·60·90일 로드맵 중 D-day 임박 액션 Top 3 | "지금 뭘 해야 하나"를 행동 단위로 제시 | 진단 `result.roadmap` 파싱 |
| 6 | **팀원 권한/역할 카드** | 멤버 목록과 역할(owner/admin/editor/viewer) | 기업 계정에서 누가 무엇을 할 수 있는지 확인 | membership (※API 신규 필요) |
| 7 | **AI 진단 다시 실행 버튼** | 제품 선택 후 재진단 요청 (CTA 버튼) | 데이터 갱신 후 최신 상태로 다시 진단 | `POST /api/diagnosis` |
| 8 | **(추가 아이디어) 데이터 완성도 알림 배너** | 누락 필드/만료 임박 인증서 경고 | 진단 정확도를 떨어뜨리는 빈 데이터를 선제 안내 | 카드 2·3 데이터 가공 |

### 하위 메뉴 (카드 하단 또는 사이드)
- `📦 제품 지식 관리` → `/mypage/knowledge`
- `📋 진단 이력 전체` → `/diagnosis`
- `⚙️ 계정/회사 정보 수정` → `/mypage` 수정 모드

## 3. 화면 우선순위 (시선 흐름)

```
상단    [회사 정보 카드]           [AI 진단 다시 실행 ▶]   ← 정체성 + 핵심 액션
        ───────────────────────────────────────────
중단    [제품 지식 현황]  [최근 AI 진단 결과]            ← 현황 + 결과
        ───────────────────────────────────────────
하단    [오늘 할 일]      [리포트 보관함]  [팀원 권한]   ← 액션 + 보관 + 협업
```

- **F자 시선 흐름**: 좌상단(정체성) → 우상단(행동 유도) → 아래로 현황/결과/액션.
- 가장 중요한 "AI 진단 다시 실행"은 우상단 고정으로 항상 눈에 띄게 배치.

## 4. 상태별 처리

| 상황 | 처리 |
| :--- | :--- |
| 개인 계정(personal) | 회사 정보 카드·팀원 권한 카드 숨김 |
| 진단 이력 없음 | 최근 진단 카드에 "첫 진단을 시작해보세요" 빈 상태 + CTA |
| 등록 제품 없음 | 제품 현황 카드에 "제품을 먼저 등록하세요" 안내 |
| 진단 진행 중(pending) | 최근 진단 카드에 로딩/진행률 표시 |
| 권한 부족(viewer) | 진단 재실행·수정 버튼 비활성화 (usePermission 훅 활용) |
