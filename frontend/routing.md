### 1. 홈

| URL 경로 | 페이지 명 | 접근 | 기능 |
| :--- | :--- | :--- | :--- |
| / | 홈 | 공개 | • 로그인 전: 주요 수출국 지도 → [최근 진단], [오늘 할 일] 블라인드 처리 후 "로그인 후 이용 가능합니다" 안내 및 로그인 버튼 노출<br>• 로그인 후: 주요 수출국 지도 → 최근 진단 → 오늘 할 일 → 새 진단 시작 |
| /login | 로그인 | 공개 | 아이디(이메일) / 비밀번호 |
| /signup | 회원가입 유형 선택 | 공개 | 개인 / 기업 계정 유형 선택 화면 |
| /signup/personal | 개인 회원가입 | 공개 | 이름, 아이디, 이메일, 비밀번호 |
| /signup/company | 기업 회원가입 | 공개 | 담당자명, 아이디, 이메일, 비밀번호, 기업명, 사업자번호, 업종 |

### 2. AI 진단

| URL 경로 | 페이지 명 | 접근 | 기능 |/ failed), 제품명, 요청일 표시 |
| `/diagnosis/new` | 새 진단 시작 | 인증 필요 | • 좌측 고정 단계 바(11단계)<br>• 제품명 및 HS Code 직접 입력<br>• "저장된 제품 지식 불러오기" 버튼을 통한 `/mypage/knowledge` 등록 제품 선택 및 연동<br>• 제품 선택 시 해당 제품 지식 스냅샷의 진단 입력값 자동 반영 |
| `/diagnosis/:id` | AI 진단 결과 | 인증 필요 | • 수출 준비도 점수, 규제·인증 분석, 시장/리콜/FTO 결과, 매칭 지원사업, 실행 로드맵 시각화<br>• 우측 제품 지식 인스펙터 패널 (접기/펼치기 가능, 읽기 전용): 진단 활용 제품 지식 스냅샷 기반의 신뢰도 등급·만료 임박 인증서·누락 필드 요약 제공 |
| `/diagnosis/:id/sources` | 진단 근거 및 출처 | 인증 필요 | • 진단 결과의 공공데이터 근거 원문(관세청·KOTRA·SafetyKorea 등) 조회<br>• 제품 지식 출처 문서 목록 조회 |

### 3. 마이페이지

| URL 경로 | 페이지 명 | 접근 | 기능 |
| :--- | :--- | :--- | :--- |
| /mypage | 마이페이지 | 인증 필요 | 계정 정보 조회 및 수정. 기업 계정이면 회사 정보(기업명·업종) 추가 표시. 하위 메뉴: 제품 지식 관리, 진단 이력 |
| /mypage/knowledge | 제품 지식 관리 | 인증 필요 | 등록된 제품 목록 카드형 표시. 제품별 신뢰도 등급/만료 임박 인증서 수/최근 수정일 요약. "신규 제품 등록" 버튼, "저장된 제품 지식 불러오기" 버튼 → "AI 진단에 반영" 버튼(`/diagnosis/new`로 이동하면서 해당 제품 선택 상태로 전달) |
| /mypage/knowledge/new | 제품 등록 | 인증 필요 | 제품명, 카테고리, 설명 입력. 등록 완료 후 `/mypage/knowledge/:productId`로 이동 |
| /mypage/knowledge/:productId | 제품 상세 조회 | 인증 필요 | 제품 기본 정보, 인증서(만료일·갱신 주기), FTO, 바이어 요구사항, 신뢰도 등급, 변경 이력(Audit Log) 탭 구성으로 표시 |
| /mypage/knowledge/:productId/edit | 제품 수정 | 인증 필요 | 제품 기본 정보 및 지식 항목 수정. 저장 시 Audit Log 자동 기록 |
