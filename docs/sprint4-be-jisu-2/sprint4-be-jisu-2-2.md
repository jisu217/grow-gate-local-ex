### 피드백 요청 사항

과제 2번: `2) productId가 있으면 현재 사용자에게 접근 가능한 제품인지 검증합니다.`

### 검증 로직

| 단계 | 위치 | 조건 | 결과 |
| :--- | :--- | :--- | :--- |
| 역할 검증 | `requireDiagnosisPermission` (:318-326) | 멤버십 역할 없음 | `403 FORBIDDEN` |
| 역할 검증 | 〃 | 역할 = `viewer` | `403 FORBIDDEN` |
| 소유/소속 검증 | `findProductByUser` (:328-336) | 회사 소속 → `company_id` 조건 불일치 | `404 NOT_FOUND` |
| 소유/소속 검증 | 〃 | 개인 계정 → `owner_id` 조건 불일치 | `404 NOT_FOUND` |

다른 회사/사용자의 `productId`, 삭제된 제품(`deletedAt` 존재)은 모두 조회 조건 자체에서 걸러져 `404 NOT_FOUND`로 귀결되며, 이는 타인 리소스의 존재 여부를 노출하지 않기 위한 의도적 처리로 완료 기준(403 또는 명확한 비즈니스 에러)을 충족함
