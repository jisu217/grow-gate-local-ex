# Proof Pack

This directory is generated by `scripts/build-proof-pack.sh`.

## Commands

```bash
./scripts/build-proof-pack.sh
./scripts/check-proof-pack.sh
```

`build-proof-pack.sh` prefers deployed-server exports under `artifacts/live-public-data-smoke/latest/`. If those files do not exist, it writes a clearly marked redacted sample pack with `proofSource=packaged-redacted-sample_not_deployed_live_export` so the repository structure and validators remain reproducible. Replace sample files with deployed proof exports before a final live presentation.

The public-data section passes only after a deployed server exports an actual proof run with:

- `liveProviderCount >= 3`
- `motieRelatedLiveCount >= 2`
- live/cache providers containing `rawResponseSha256`
- no unredacted API keys

Synthetic validation remains persona-based and must not be presented as real customer interviews.
