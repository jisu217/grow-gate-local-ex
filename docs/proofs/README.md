# Proof Pack

This directory is generated by `scripts/build-proof-pack.sh`.

The public-data section passes only after a deployed server exports an actual proof run with:

- `liveProviderCount >= 3`
- `motieRelatedLiveCount >= 2`
- live/cache providers containing `rawResponseSha256`
- no unredacted API keys

Synthetic validation remains persona-based and must not be presented as real customer interviews.
