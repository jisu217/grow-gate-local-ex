# Limitations

**Global disclaimer:** synthetic, not real customer data, persona-based validation.

- This is not real customer interview evidence.
- The persona names, company names, tasks, objections, time estimates, and willingness-to-pay values are synthetic.
- Time reduction is calculated from scripted persona task assumptions, not measured production logs.
- Willingness-to-pay values are directional and synthetic; they do not indicate actual purchase intent.
- Legal, certification, patent, recall, and customs judgments require expert review.
- KIPRIS/FTO output is a red-flag aid and must not be presented as legal opinion.
- Public-data proof must come from live/cache records with operation endpoint, API key configured, raw hash, and schema PASS.
- Fallback and seed data must not create positive Gate contribution.
- The deterministic rule score and risk/fallback conditions own the final Gate; LLM output must not override `finalGate`.
- Any presentation must say this is actual validation preparation, not completed real customer validation.
