## Runtime Provider Notes

Current Spring runtime providers include `KCS_TRADE`, `KCS_TARIFF_LOGISTICS`, `KOTRA_MARKET`, `SAFETY_RECALL`, `MOTIE_IMPORT_REGULATION`, `TRADE_SECURITY_HSK_LINKAGE`, `KIPRIS_FTO`, and `BIZINFO_SUPPORT` by default. `MOTIE_WEB_CRAWL` and `EXPORT_EVIDENCE_FEED` are conditional connectors controlled by `PUBLIC_DATA_CRAWL_ENABLED` and `PUBLIC_DATA_EXPORT_EVIDENCE_ENABLED`.

KCS HS/관세율/운송비 reference is represented as a curated cache CSV, not an operation API call. It was generated from the user-provided `관세청_HS부호_20260101.xlsx`, `관세청_품목번호별 관세율표_20260211.xlsx`, and three `20260531` freight CSV files for the demo HS prefixes `850760`, `848180`, `902519`, and `730630`. The Spring connector returns `sourceType=cache`, `operationEndpoint=false`, and a capped deterministic contribution only when both HS and country-route rows match. It must not be described as legal tariff confirmation, quote-ready logistics cost, customs clearance approval, or an LLM-driven decision.
